# Geonorge.Rapportgenerator

Generering av rapporter for ulike datasett

## Kom i gang

### Forutsetninger

- .net framework 4.7.2

### Oppsett

1. Klon repoet:
   ```bash
   git clone git@github.com:kartverket/Geonorge.Rapportgenerator.git
   cd Geonorge.Rapportgenerator
   ```

2. Installer avhengigheter:
   ```bash
   yarn install
   ```
